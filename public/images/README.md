# SceneBuzz Media Library

Use this folder for editorial image assets. Keep one folder per subject so images remain easy to replace and audit.

```text
images/
├── celebrities/
│   ├── pakistan/<slug>/
│   └── india/<slug>/
├── cricket/
│   ├── players/<slug>/
│   ├── teams/<slug>/
│   └── competitions/<slug>/
├── dramas/pakistan/<slug>/
├── movies/bollywood/<slug>/
└── site/
```

## Required attribution

Every externally sourced image should have matching metadata in the relevant content record:

- `photographer`: photographer name when known
- `source`: agency/publication/source
- `license`: `owned`, `licensed`, `permission`, `creative_commons`, or `public_domain`
- `credit`: exact credit wording required by the rights holder
- `originalUrl`: original/source page when available
- `obtainedAt`: optional date obtained
- `usageNotes`: optional restrictions or notes

**Credit is not permission.** Do not publish an image merely because it was found online or because a photographer/source is credited. Confirm that SceneBuzz has the right to use it.

For new assets, prefer a licensed, commissioned, owned, permission-based, Creative Commons, or public-domain source whose terms permit the intended use. Do not remove required attribution or crop out watermarks/credits.
